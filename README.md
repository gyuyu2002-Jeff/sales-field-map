## ⚡ 效能與負擔分析（全台 13,424 家廠商依然流暢 60 FPS 的關鍵）

1. **地圖標記按需加載 (On-Demand Marker Rendering)**：
   - 地圖**絕不會**同時掛載上萬顆圖釘，而是根據您目前切換的園區「僅渲染該園區的 50~480 顆標記」，GPU 與 CPU 負載極輕。
2. **DOM 切片虛擬載入 (Slice Lazy-Loading)**：
   - 左側客戶列表每次只渲染 60 筆卡片，向下滾動時增量載入，記憶體佔用小於 15MB，手機滑動維持 **60 FPS** 極致流暢。
3. **分區 Storage 獨立隔離**：
   - 每個工業區的拜訪狀態與筆記各自擁有獨立的儲存空間，切換縣市時互不干擾，資料永不流失。

## 🌟 核心功能特色

### 1. 📍 首次進入預設常駐縣市自訂（支援個人化記憶與隨時變更）
- **首次登入智能詢問**：外勤人員第一次開啟系統時，自動彈出親切設定視窗，直接挑選日常主要常駐縣市（預設為桃園市），一鍵確認並記住偏好。
- **頂部工具列即時顯示與變更**：頂部常駐 `⭐ 預設: 桃園市` 按鈕，日後若調動巡訪責任區，隨時點擊即可秒更換預設常駐縣市。
- **預設勳章高亮**：在縣市切換列上，您的預設常駐縣市會自動佩戴金色 `⭐預設` 徽章，一眼即辨。

### 2. 乾淨純粹的縣市切換列（無冗長標籤干擾）
- **第一層：縣市切換列 (`#countyNavBar`)**：移除冗長的「西部/東部」文字標籤，18 縣市嚴格依循地理動線依序排列，節省螢幕空間，一鍵秒切。
- **第二層：園區切換列 (`#parkNavBar`)**：自動載入該縣市所屬之各大科學園區與工業區，地圖平滑飛至該區核心。

### 3. 專注單一園區搜尋（無跨區干擾）
- 搜尋引擎完全局限在**當前所選園區**或**當前縣市總覽**，打字即搜，支援注音/拼音/倉頡輸入法，絕不跳出跨縣市干擾提示，乾淨高效。

### 4. 快速篩選上市櫃大廠
- 點擊 `⭐ 上市櫃`，立刻精準過濾出各園區的核心上市櫃指標大廠，鎖定大型拜訪標的。

### 5. 結構化拜訪內容紀錄系統 (Visit Log CRM)
- 在任何卡片或地圖釘點擊 `📋 拜訪紀錄`，即可 1 分鐘快速紀錄：
  - 📅 **拜訪日期與時間**（系統自動預設現在時間，可微調）
  - 👤 **接洽對象與職稱**（例：陳廠長、採購部林專員）
  - 🎯 **洽談階段進度**（初次接洽、確認規格需求、樣品測試中、已提報價單、成交簽約、定期維護、暫無需求）
  - 💬 **洽談重點與客戶需求內容**（痛點、使用品牌、預計採購量、報價期限等）
  - ⏰ **下次預計待辦事項與回訪日**（例：下週三送樣品、10/25提供報價）
- **歷史拜訪時間軸**：同一家客戶可累積多次拜訪紀錄，按時間倒序排列。
- **卡片即時摘要**：卡片上醒目顯示最新一次拜訪的日期、對象、進度標籤、內容摘要與綠色待辦事項。
- **CSV 匯出完整報表**：點擊 `📤 匯出記錄`，自動匯出包含縣市、園區、拜訪歷程、最新進度與待辦事項之 CSV檔。

### 6. 動態同路巡訪快篩（Street-by-Street Proximity）
- 到了各園區主要幹道（如「力行路」、「中科路」、「科技一路」、「加昌路」），點一下路名標籤，立刻列出該路段上的所有客戶，外勤順路拜訪效率翻倍。

### 7. 一鍵 Google Maps 導航
- 每家廠商卡片與地圖點位彈窗均配備 `🚗 導航` 按鈕，在手機上點擊直接呼叫 Google Maps App 規劃路線。

### 8. 每月政府公開資料自動同步機器人 (GitHub Actions Bot)
- **定期自動巡檢**：每月 1 號上午 10:00（UTC 02:00），GitHub Actions 自動在雲端啟動機器人。
- **對齊官方登記**：連線經濟部產業發展署登記工廠資料庫，自動檢驗最新家數與廠址。
- **保護外勤資產**：更新時嚴格保留使用者已標記之「已拜訪進度」、「訪談內容紀錄 (visit_logs)」與「備忘筆記」，絕不覆蓋或丟失。
### 9. 📱 全新 RWD 響應式設計（手機 / 平板 / 電腦極致流暢）
- **底部浮動模式切換列 (`#mobileViewToggle`)**：
  - 手機端提供常駐懸浮膠囊控制器，外勤在現場可一鍵秒切：
    - `📋 廠商名單 (N)`：專注瀏覽客戶卡片、快速查找電話與訪談歷程。
    - `⚖️ 分割視圖`：上半部地圖、下半部名單，同步掌握空間與清單。
    - `🗺️ 地圖視野`：全螢幕高解析地圖，行車開車、辨識周邊廠區最直覺。
- **原生抽屜式 Bottom Sheet 視窗**：
  - 手機端開啟「📋 拜訪紀錄」或「➕ 新增客戶」時，彈窗自動轉化為原生滑動底抽（Bottom Sheet），支援 iOS/Android `safe-area-inset-bottom` 避讓，大拇指單手操作極致順手。
- **智慧觸控連動**：
  - 在手機名單模式點擊任一客戶卡片，系統自動切換至分割/地圖模式並平滑飛入 (`flyTo`) 廠家位置，自動彈出詳細資訊框。
- **頂部工具列自適應摺疊**：
  - 手機版自動隱藏冗長副標題，精簡化匯入/匯出/新增按鈕，螢幕空間最大化保留給地圖與客戶卡片。

## 📁 檔案架構

- `index.html`：單一純前端網頁應用程式（零伺服器、全離線可用、整合 13,424 家廠商資料）。
- `taiwan_parks_database.json`：全台 18 縣市、72 大工業與科技園區、13,424 家廠商資料庫。
- `all_taoyuan_parks.json`：桃園 7 大園區備援資料檔。
- `build_index_html.py`：雙層架構靜態 HTML 編譯器。
- `generate_all_taiwan_parks.py`：全台園區資料庫生成擴充工具。
- `scripts/update_government_data.py`：每月政府工廠資料自動同步機器人。
- `.github/workflows/auto-update-data.yml`：GitHub Actions 每月排程工作流。
