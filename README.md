# 🗺️ 桃園外勤巡訪地圖總中樞 (Taoyuan Industrial Parks Sales Hub)

> **專為業務人員外勤拜訪打造的客戶地圖與動線規劃系統。**  
> 擺脫傳統房仲/商仲網站繁雜的房產篩選，聚焦在 **「客戶在哪裡」、「這條路還能拜訪誰」、「一鍵開 Google 導航」** 與 **「拜訪備忘與狀態追蹤」**。  
> 全面涵蓋桃園 **7 大核心工業區 / 產業園區**，合計 **1,874 家廠商**！

### 🌐 [👉 點此直接在線上使用（GitHub Pages 官方免安裝版）](https://gyuyu2002-jeff.github.io/sales-field-map/)
> 支援手機 Safari / Chrome 直接開啟，點擊「加入主畫面」即可如原生 App 般隨身查閱！

## 🌟 核心功能特色

### 1. 桃園 7 大工業園區全收錄（合計 1,874 家廠商，全部預設「尚未拜訪」）
- 🏢 **中壢產業園區**：744 家（台達電、欣興、精材、統一、東元、三陽、采鈺等）
- 🏢 **龜山產業園區**：220 家（廣達總部、英業達、欣興山鶯廠、南僑、穩懋等）
- 🏢 **華亞科技園區**：100 家（台灣美光晶圓總部、南亞科、HTC、友達、致茂等）
- 🏢 **平鎮產業園區**：120 家（敬鵬、燿華、台達電平鎮廠、聯茂、台灣櫻花等）
- 🏢 **觀音產業園區（含桃科）**：350 家（台光電、東和鋼鐵、國喬石化、台玻、世紀鋼等）
- 🏢 **大園產業園區（含航空城）**：230 家（正隆紙業、大園汽電、聯華氣體、嘉里大榮、遠雄自貿港等）
- 🏢 **幼獅產業園區**：110 家（景碩、統一超商大型低溫物流中心、益登、光頡等）
- 🌐 **全桃 7 大園區總覽**：一鍵開啟全桃園 1,874 家廠商全景地圖！

### 2. 頂部多園區一鍵切換列（Park Switcher）
- 頂部導航列支援橫向滑動與點擊，一鍵秒級切換園區。地圖自動平滑飛至該園區中心，動態載入該園區的專屬路名與產業統計。

### 3. 強大智慧搜尋引擎（全中文輸入法優化）
- **即時反應**：支援注音、倉頡、拼音輸入法，打完即搜；支援鍵盤 `Enter` 鍵立即搜尋。
- **貼心控制**：附有 `🔍 搜尋` 按鈕與 `✕` 一鍵清除按鈕。
- **多關鍵字容錯**：支援空格分隔多組關鍵字（如 `台達 中園`、`欣興 龜山`）。
- **智慧跨區搜尋提醒**：若在當前園區找不到客戶，系統會自動搜尋其他 6 個園區並貼心提示（例如：「在中壢未找到，但在【華亞科技園區】找到台灣美光晶圓！[點此一鍵前往]」）。
- **解除標籤限制提示**：若搜尋結果因路段或產業標籤被濾除，自動提供「一鍵解除限制」按鈕。

### 4. 快速篩選上市櫃大廠
- 點擊 `⭐ 上市櫃`，立刻精準過濾出各園區的核心上市櫃指標大廠，鎖定大型拜訪標的。

### 5. 動態同路巡訪快篩（Street-by-Street Proximity）
- 業務到了「中園路」、「吉林路」、「山鶯路」或「科技一路」，點一下路名標籤，立刻列出該路段上的所有客戶，外勤順路拜訪效率翻倍。

### 6. 一鍵 Google Maps 導航
- 每家廠商卡片與地圖點位彈窗均配備 `🚗 導航` 按鈕，在手機上點擊直接呼叫 Google Maps App 規劃行車/步行路線。

### 7. 結構化拜訪內容紀錄系統 (Visit Log CRM)
- **外勤即時紀錄**：在「✅ 已拜訪」客戶或任何廠商卡片上點擊 `📋 拜訪紀錄`，或點擊 `✓ 標記為已拜訪`，即自動彈出訪談紀錄表單，方便業務在離開客戶廠區、坐進車內時 1 分鐘快速紀錄：
  - 📅 **拜訪日期與時間**（系統自動預設現在時間，可微調）
  - 👤 **接洽對象與職稱**（例：陳廠長、採購部林專員）
  - 🎯 **洽談階段進度**（初次接洽、確認規格需求、樣品測試中、已提報價單、成交簽約、定期維護、暫無需求）
  - 💬 **洽談重點與客戶需求內容**（痛點、使用品牌、預計採購量、報價期限等）
  - ⏰ **下次預計待辦事項與回訪日**（例：下週三送樣品、10/25提供報價）
- **歷史拜訪時間軸**：同一家客戶可累積多次拜訪紀錄，按時間倒序排列，清楚掌握歷次互動進度。
- **卡片即時摘要**：卡片上醒目顯示最新一次拜訪的日期、對象、進度標籤、內容摘要與綠色待辦事項。
- **「已拜訪」專屬彙整檢視**：切換至 `✅ 已拜訪` 標籤時，頂部自動顯示已訪廠商數與累計拜訪紀錄筆數。
- **CSV 匯出完整報表**：點擊 `📤 匯出記錄`，除了基本資料外，自動包含每家客戶的「拜訪次數、最新拜訪日期、接洽窗口、洽談階段、訪談內容摘要、下次待辦」，直接作為週會/月會業務報告！

### 8. 外勤 GPS 即時定位
- 點擊右上角 `🎯 我的位置`，立即透過手機 GPS 標定業務目前所在地點，查看周圍最近的目標工廠。

### 9. Excel / CSV 批次匯入與匯出
- 可匯出最新拜訪名單與備忘（回公司報備或向主管彙整報告）。
- 支援以 Excel 編輯名單後儲存為 CSV 重新匯入。

### 10. 每月政府公開資料自動同步機器人 (GitHub Actions Bot)
- **定期自動巡檢**：每月 1 號上午 10:00（UTC 02:00），GitHub Actions 自動在雲端啟動機器人。
- **對齊官方登記**：自動連線經濟部產業發展署與政府資料開放平台（data.gov.tw）登記工廠資料庫，盤點最新家數與廠址。
- **保護外勤資產**：更新時嚴格保留使用者已標記之「已拜訪進度」、「訪談內容紀錄 (visit_logs)」與「備忘筆記」，絕不覆蓋或丟失任何既有外勤成果。
- **全自動建置發布**：比對更新後自動重新編譯 `index.html` 並觸發 GitHub Pages 部署，零主機費、零維護成本。
- **支援隨時手動觸發**：亦可在 GitHub 儲存庫的 **Actions** 分頁找到「每月定時自動同步政府公開工廠資料」，點擊 **`Run workflow`** 即刻手動執行！
