# 🗺️ 業務外勤巡訪地圖系統 (Field Sales Visit Map)

> **專為業務人員外勤拜訪打造的客戶地圖與動線規劃系統。**  
> 擺脫傳統房仲/商仲網站繁雜的房產篩選，聚焦在 **「客戶在哪裡」、「這條路還能拜訪誰」、「一鍵開 Google 導航」** 與 **「拜訪備忘與狀態追蹤」**。

### 🌐 [👉 點此直接在線上使用（GitHub Pages 官方免安裝版）](https://gyuyu2002-jeff.github.io/sales-field-map/)
> 支援手機 Safari / Chrome 直接開啟，點擊「加入主畫面」即可如原生 App 般隨身查閱！

---

## 🌟 核心功能特色

1. **同路巡訪快篩（Street-by-Street Proximity）**
   - 業務到了「中園路」或「吉林路」，點一下路名標籤，立刻列出該路段上的所有客戶與大廠，外勤順路拜訪效率翻倍。
2. **一鍵 Google Maps 導航**
   - 每家廠商卡片均配備 `🚗 導航` 按鈕，在手機上點擊直接呼叫 Google Maps App 規劃行車/步行路線。
3. **直覺拜訪狀態與備忘錄**
   - 支援切換 `⏳ 待拜訪`、`💬 洽談中`、`✅ 已拜訪`，地圖標記即時變換顏色。
   - 支援點擊 `✏️ 備忘` 即時記錄拜訪重點、窗口喜好或注意事項，自動儲存至瀏覽器本地（LocalStorage），離線也能看。
4. **外勤 GPS 即時定位**
   - 點擊右上角 `🎯 我的位置`，立即透過手機 GPS 標定業務目前所在地點，查看周圍最近的目標工廠。
5. **Excel / CSV 批次匯入與匯出**
   - 可匯出最新拜訪名單與備忘（回公司報備或向主管彙整報告）。
   - 支援以 Excel 編輯名單後儲存為 CSV 重新匯入。
6. **零伺服器、零資安疑慮（BYOD & Zero-Server）**
   - 純靜態 HTML/JS，點擊即可開啟，不需任何後端資料庫，客戶名單僅保存在使用者自己設備上，不外洩。

## 🚀 快速使用指南

### 方法一：電腦直接雙擊開啟
雙擊資料夾內的 `啟動業務巡訪地圖.bat`（或直接將 `index.html` 拖入 Chrome / Edge 瀏覽器）。

### 方法二：在手機上使用
1. **GitHub Pages 免費託管（最推薦）**：
   - 將本專案（`index.html` 與 `sample-clients.csv`）上傳到私有或公開 GitHub Repository。
   - 開啟 Settings -> Pages，即可得到一個專屬網址，業務隨時在手機 Safari 或 Chrome 打開，還可「加入主畫面」當作 App 使用。
2. **手機直接開檔**：
   - 直接把 `index.html` 透過 LINE 或 AirDrop 傳給手機，在瀏覽器打開即可離線使用。
