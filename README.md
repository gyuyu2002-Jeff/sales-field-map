# 全台科技＆產業園區巡訪地圖

[開啟網站](https://gyuyu2002-jeff.github.io/sales-field-map/)

支援園區、產業與路段篩選、拜訪紀錄、導航及本機客戶名單。

**資料品質：既有名冊含程式生成的公司名稱、電話、聯絡人及座標，未逐筆核對。不可當成官方已驗證名冊。**
`generate_*` 是既有資料生成工具，包含隨機示範內容。目前沒有實作政府名冊同步。
每月排程僅執行格式與功能檢查，不會把連線成功標示為官方驗證，也不會寄出更新成功通知。

## 保存與備份

- 拜訪紀錄僅存於目前裝置與瀏覽器，沒有帳號或雲端同步。
- 「完整備份」下載 JSON，包含所有已保存園區、自建客戶、完整拜訪歷程與偏好。
- 「匯入名單」可選 JSON 還原，先下載目前備份，再以單次儲存還原。
- CSV 是目前範圍的摘要，僅有最新拜訪內容，不能取代完整備份。
- CSV 匯入需先選單一園區，必要表頭為「公司名稱」。支援中文／英文表頭、引號與換行。
- 匯入前顯示筆數及待定位數，可選追加、覆蓋或取消。覆蓋前下載備份，缺座標不顯示地圖標記。
- 清除網站資料、無痕模式與更換裝置可能遺失紀錄。備份檔含聯絡資訊與私人筆記，請妥善保管。
- 舊版保存紀錄會自動讀取並於儲存時遷移；原始鍵不刪除。

## 開發與驗證

需要 Python 3.11+、Node.js 22+：

```sh
npm ci
python scripts/update_government_data.py
npx playwright install chromium
npm test
```

Windows 測試使用已安裝的 Microsoft Edge；Linux 使用 Playwright Chromium。
測試自動啟動並停止本機伺服器，不會寫入線上網站。

`build_index_html.py` 是頁面來源，修改後執行 `python build_index_html.py`。
`data-tools.js` 處理驗證、CSV 與安全編碼；`app-support.js` 處理保存、備份與按需載入。
產生的 `index.html`、`data/*.json` 一併提交，資料檔含內容雜湊，避免版本混用。
Leaflet 1.9.4 隨站提供並保留授權及完整性校驗；地圖圖磚仍需網路。

首頁只載入所選園區，全台總覽才載入其餘園區。地圖使用可見區域及群聚標記減少 DOM。
GitHub Pages 從 `main` 根目錄部署，推送前先完成本機回歸測試。

正式官方同步仍需：合法資料集、工廠登記／統編等穩定識別碼、逐筆來源與時間、地址座標核對、異動預覽與失敗保護。不得只更新日期或驗證旗標。
